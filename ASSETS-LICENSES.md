# Nova, asset licenses

## Photography

All 8 photographic compositions in `public/assets/images/t001-nova/` were generated specifically for Nova by WebScale using the OpenAI image model on 2026-11-07. They depict fictional people, an invented building and unbranded objects. The 92 responsive WebP and AVIF files below may be redistributed in the template package. No external stock-photo license is required for these files.

The original file names, dimensions and responsive variants are preserved. Local build inputs in `src/assets/raw/t001-nova/` are WebP copies of the same 8 generated compositions; they are not distributed. Generation used the built-in OpenAI image tool, followed by `optimize_image.py` (WebP q85, metadata stripped) and resampling to the original pixel sizes. The project build produces WebP derivatives at quality 80 and AVIF derivatives at quality 50.

The local font files and icon package retain their separate upstream licenses. The site logo and favicon are template branding; this photography inventory does not change their status.
